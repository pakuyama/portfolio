- **비주얼 컨셉**: **미니멀 & 모던 (Minimal & Modern)**

  - `Background`: 클린 화이트 (`#FFFFFF`) 또는 극미세 그레이 (`#F9FAFB`)
  - `Surface / Card`: 소프트 그레이 (`#F3F4F6`) 및 얇은 보더 라인 (`#E5E7EB`)
  - `Text Primary`: 딥 차콜/블랙 (`#111827`)
  - `Text Secondary`: 미디엄 그레이 (`#6B7280`)
  - `Accent / Key Color`: 신뢰감을 주는 모던 블루/인디고 (`#2563EB`) 또는 미니멀 모노크롬 하이라이트
- **타이포그래피**: 산세리프(Sans-serif) 폰트 (Pretendard, Inter) 기반의 또렷한 굵기 대비와 넉넉한 자간/행간
- **인터랙션**: 절제된 호버(Hover) 효과, 부드러운 스크롤 이동, 명확한 포커스 표시

### 섹션 2: 히어로 (Hero Section) — 첫인상과 가치 제안
- **목표**: 3초 안에 방문자에게 이름, 정체성, 주력 분야를 각인시키고 가장 중요한 행동(PDF 다운로드)을 유도

  - 태그라인: `Hello, World! I am Yunha Kim`
  - 메인 타이틀: `사용자에게 필요한 것을 빠르게 만들고 개선하는 개발자, 김윤하입니다.`
  - 서브 카피: `웹 프론트엔드부터 서비스 구현, 반복 업무를 줄이는 자동화 스크립트까지 — 문제를 직시하고 코드로 답을 찾아냅니다.`
- **CTA 버튼 그룹**:
  - Primary: `[ 상세 이력서 (PDF) ]` *(클릭 시 새 탭 열기 또는 다운로드)*
  - Secondary: `[ 프로젝트 보러가기 ]` *(클릭 시 #projects 섹션으로 스무스 스크롤)*

### 섹션 3: 소개 및 핵심 가치 (About Me)
- **목표**: 제너럴리스트이자 크리에이터로서의 강점을 3가지 포인트로 압축 전달
- **소개 글**:
  > "단순히 코드를 작성하는 것을 넘어, 제품이 해결해야 할 본질적인 문제에 집중합니다.  
  > 사용자 경험을 해치지 않는 깔끔한 UI와 데이터 흐름의 안정성을 함께 고민하며,  
  > 아이디어를 가장 빠르고 견고하게 세상에 내놓는 과정을 즐깁니다."
- **3대 핵심 역량 카드**:

  2. **효율성을 높이는 자동화 (Automation & Scripting)**: 반복 작업을 자동화하여 생산성을 극대화하는 툴 제작
  3. **끝까지 완성하는 책임감 (Ship Fast, Iterate Often)**: 기획 단계에서 멈추지 않고 배포와 피드백까지 완결

### 섹션 4: 핵심 프로젝트 쇼케이스 (Featured Projects)
- **목표**: 실전 개발 역량을 입증하는 3~4개의 프로젝트 카드 배치
- **카드 공통 구성**:
  - `썸네일 이미지`: 직관적인 UI 캡처 또는 아키텍처 다이어그램
  - `카테고리 태그`: e.g., Web App, Automation, Full-stack
  - `프로젝트 제목`: 서비스/프로젝트 이름
  - `한 줄 요약`: 해결한 문제와 주요 성과
  - `기술 스택 배지`: e.g., React, Tailwind CSS, Python, Node.js
  - `액션 링크`: `[Live Demo ->]` / `[GitHub Repo ->]`

#### [카드 1] 실시간 인터랙티브 웹 대시보드 / 서비스
- **역할/분야**: 웹 프론트엔드 & 사용자 경험
- **설명**: 방대한 데이터를 한눈에 파악할 수 있도록 시각화하고 빠른 반응 속도를 제공하는 반응형 웹 서비스.
- **주요 성과**: Lighthouse 성능 점수 95점 이상 달성, 직관적인 필터링 시스템 구축.

#### [카드 2] 업무 효율화를 위한 워크플로우 자동화 봇/툴
- **역할/분야**: 스크립팅 & 자동화 (Automation)
- **설명**: 반복적인 데이터 수집, 가공 및 알림 전송을 자동화하여 수작업 시간을 80% 이상 단축한 자동화 파이프라인.
- **주요 성과**: 안정적인 에러 핸들링 및 스케줄러 기반 무중단 배치 작업 수행.

#### [카드 3] 모던 웹 애플리케이션 (SPA)
- **역할/분야**: 컴포넌트 설계 & 상태 관리
- **설명**: 모듈화된 재사용 가능 컴포넌트 구조로 유지보수성을 극대화한 서비스 프로토타입.
- **주요 성과**: 클린 아키텍처 기반 상태 관리 적용, 직관적인 사용자 온보딩 구현.

#### [카드 4] 오픈소스 / 유틸리티 라이브러리 (또는 실험적 사이드 프로젝트)
- **역할/분야**: 크리에이티브 코딩 & 오픈소스
- **설명**: 개발자 경험(DX)을 개선하기 위해 자체 제작하여 배포한 오픈소스 도구 또는 인터랙티브 실험작.

## 6. 개발 및 실행 연계 계획 (kit 기준)

- **HTML 버전 (`index.html`)**:
  - 시맨틱 마크업(`header`, `main`, `section`, `article`, `footer`)을 철저히 준수하여 SEO와 접근성 확보
  - Vanilla JS(`src/vanilla.js`)를 통해 이메일 복사 인터랙션, 스크롤 스파이 네비게이션, 모달/이력서 다운로드 이벤트 제어
- **React 버전 (`react.html` / `src/App.jsx`)**:
  - 프로젝트 카드 목록을 JSON 형태의 데이터 배열(`projectsData`)로 분리하여 유연한 추가/수정 가능 구조 설계
  - `ProjectCard`, `SkillBadge`, `ContactForm` 등 컴포넌트 단위 분리
- **공통 스타일 (`src/styles/tokens.css`, `layout.css`)**:
  - 모노톤 컬러 변수 및 여백 토큰 정의를 통한 미니멀 & 모던 감성 구현
  - 모바일, 태블릿, 데스크톱 완벽 대응 반응형 그리드(`grid`, `flex`) 적용
